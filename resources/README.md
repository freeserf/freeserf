# Resources

Additional images and the font used by FreeSerf that are not part of the
original game data. They are drawn in the style of the original graphics.

| File | Size | Description |
|---|---|---|
| `button-advanced.png` | 56×16 | "Advanced" button in the style of the original "Save" and "Load" buttons (icons 224 and 225): wooden plate with the edges of the "Save" button and the wood of the "Start" button, yellow letters with a dark outline. A, D, V and E are taken from "Save" and "Load", N and C and the large A are drawn in the same style. |
| `settlers.ttf` | 16 px per em | Font of the texts, family "Settlers". The glyphs of the original DOS font (Latin capitals, Ä Ö Ü, digits, `. - : ? %`) with the pixels doubled and the steps smoothed with Scale2x; the game rasterizes it at 16 pixels and reduces it by 2×2 blocks to the original pixels. Drawn in the same style: Latin lower case letters, Cyrillic, the punctuation and symbols of ASCII and Latin-1, and the letters with accents of Latin-1 and Latin Extended-A for the European languages. |
